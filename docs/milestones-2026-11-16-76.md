# Moving series and film folders — milestones 72–76

Kitsunarr could not change a title's folder: Sonarr's path edit, its series editor root-folder
change and `MoveSeriesService` were missing. A title moved by hand outside Kitsunarr could
not be pointed at its new folder either.

## Behaviour (72–74)

`kitsunarr-library::move_title` ports `MoveSeriesService.MoveSingleSeries` for series and
films:

- **Moving:** with "move files" on, the folder is renamed, or copied then removed when the new
  folder is on another file system. A failed copy removes what it wrote and keeps the source.
  If the database update fails after a move, the folder is moved back.
- **Recording only:** with "move files" off, only the recorded folder changes, for files
  already moved by hand.
- **Missing source:** if the old folder is gone and the new one exists, the move counts as done
  already. If both are missing, the change is refused for a title with files, else recorded.
  These cases follow upstream.
- **What follows the folder:** episode files, film features, sidecars and retained versions are
  stored relative to the title's folder, so their records follow without changes. The root
  folder is recomputed as the deepest configured root folder containing the new folder.

Kitsunarr is stricter than upstream about the destination. It must be an absolute path inside
a configured root folder, without `..`. It must not be, hold or sit inside another title's
folder, or the title's own folder. When files are moved, it must be missing or empty; upstream
merges into an existing folder.

## API and interface (75)

| Route | Behaviour |
|---|---|
| `PUT /api/v1/series/{id}/path`, `PUT /api/v1/movies/{id}/path` | `{path, moveFiles}` (default `true`) → the new folder, root folder and whether files moved |
| `POST /api/v1/series/move` | `{ids, rootFolderPath, moveFiles}`: each series keeps its folder below its root folder (a group's `{group}/{member}` layout survives); failures are listed and do not stop the others |
| `PUT /api/v3/series/{id}?moveFiles=true` | A changed `path` is moved (or only recorded without `moveFiles`) |
| `PUT /api/v3/series/editor` | Sonarr's series editor: monitored, monitor new items, quality profile, series type, season folder, tags with `applyTags` (add/remove/replace), and a root folder with `moveFiles` |

Series and film pages have a **Move folder** dialog (root folder, folder below it, a preview
and the "move the files" switch). The series library's bulk bar has **Move to root folder…**.

Upstream names a bulk-moved series' folder from the naming format. Kitsunarr keeps the folder's
path below its old root folder instead, so Tanukarr group layouts are not flattened.
