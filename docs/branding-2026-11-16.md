# Kitsunarr logo redesign — 16 November 2026

The new original SVG mark depicts a friendly kitsune with oversized ears, a soft cream
muzzle, bright eyes, rosy cheeks and a spirit-flame marking. It retains Kitsunarr's orange
accent and adds cream, plum ink and blush. Source artwork and exports are catalogued in
[the brand guide](../branding/README.md).

The sidebar, sign-in/setup screens, browser SVG/PNG/ICO favicons and Apple touch icon now
use the same artwork. The GitHub README has light/dark wordmarks. The exporter derives all
sizes, wordmarks and the 1280 × 640 social card from one editable mark; no new application
runtime dependencies were introduced.

Verification:

- Exports regenerate byte-for-byte with the documented tools installed.
- Transparent PNG dimensions and ICO entries (16, 32, 48 and 64 px) were checked. The mark
  was visually inspected from 16 to 512 px and on both themes. The social card is 76,223
  bytes, within GitHub's 1 MB limit.
- Formatting, diff checks, native and WebAssembly clippy, release web build and the server
  build with embedded assets passed.
- The complete existing Chromium workflow passed in 189.86 seconds, including setup,
  sidebar branding and zoom/layout checks. Dedicated checks on the existing local instance
  verified the new SVG bytes, all four favicon/touch links and light/dark login screenshots.
- The repository Dockerfile built a release image. An isolated container passed setup,
  protected API, embedded UI, healthcheck/configuration, version and graceful shutdown checks.
- The local instance at `http://127.0.0.1:8990` was updated. All seven quality profiles,
  paths/profile assignments, file records and indexer/download-client configurations matched
  the pre-deployment snapshot: 80 series, 14 movies and 428 episode files.

Local evidence is in `.dev/verification/branding/`, excluded from Git.

GitHub's repository social preview is separate from the README. Public REST/GraphQL
capabilities were inspected; `UpdateRepositoryInput` has no image field and the public
mutation schema exposes no social/image/avatar upload mutation. The available GitHub
connector also has no social-preview upload tool. The exported
[social card](../branding/github-social-preview.png) is ready for the one-time upload through
[repository Settings](https://github.com/KvasFan/Kitsunarr/settings), as described in
[GitHub's documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
This checkpoint does not claim that setting was changed or alter the owner's personal avatar.
