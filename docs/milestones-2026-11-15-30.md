## Using the new tools

- **System › Library tools › Check library** includes movie folders and feature records.
  Movie issues link to their movie page; existing series result fields remain compatible.
- **System › Library tools › Recycle bin › Restore…** offers Series or Movie destinations.
  A movie feature brings matching named subtitles, refuses an occupied feature or destination,
  and rolls back the moves if file registration fails. A subtitle restored alone must name
  the current feature. The target movie needs a registered, available root folder.
- **Activity › Manual import › Movies** scans an absolute source path without moving files.
  Review the matched movie, or choose it explicitly when the name is unknown or ambiguous.
  Select files and choose Copy (the default) or Move. Only upgrades can replace an existing
  feature; matching subtitles follow the configured file name. Per-file results retain
  failures and warnings for review. Sources already inside a library title are refused.

New files are staged before publishing. File records and import history commit together;
failed writes restore the previous feature. Replaced files go to the configured recycle
bin, or are removed after commit when no bin is configured. A file that could not be recycled
is retained in the staging folder and its path is returned as a warning. Copy mode honors
hardlink-only imports. Existing feature records are kept when a scan cannot reach its root.
