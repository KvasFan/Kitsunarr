## Changes

The Nyaa request generator now searches an ordinary anime season by title when there is no
season-specific alias and standard-format search is disabled. Missing absolute episode
metadata also falls back to the title. Standard TV queries use season/episode numbering
regardless of the anime-format switch; daily searches use dates/years. Existing season
aliases, pack filtering, episode decisions, URL escaping and query deduplication remain.
The native feed remains a single RSS page per query.

`ReleaseSearchResult.successfulIndexers` counts valid source responses, including empty feeds;
older response JSON still deserializes with the default value. Both movie and series searches
supply it. The UI distinguishes unavailable sources, partial failures and valid empty results,
provides **Search again**, and mentions Nyaa in the no-source instructions. The top-level
**Search indexers** button has an explicit revision so the same target can be searched again.
The resource tracks ordinary component props reactively, including that revision and target
changes. The first Chromium attempt caught a retry that reused results despite a changed
component key; explicit resource dependencies fix that behavior.

A native **Nyaa.si (direct)** connection was added through the local settings API after a
SQLite backup. It is enabled for interactive search only, with no tags. Existing imported
indexers and their settings are preserved. The server is served at `127.0.0.1:8990`.

## Verification

- `cargo test --workspace`: **817 passed, 0 failed, 9 ignored**; Chromium is run separately.
- Nyaa generator tests cover ordinary anime seasons without aliases, season aliases, packs,
  absolute episodes, missing absolute metadata, standard TV, daily dates/years, Unicode and
  reserved characters, and duplicate query elimination.
- Authenticated HTTP test uses a Nyaa RSS stand-in plus a failing Torznab source. It checks
  results survive partial failure, repeated requests reach Nyaa, interactive-only sources are
  excluded from automatic search, response counters distinguish empty and failing feeds,
  and OpenAPI/legacy JSON cover the new field.
- Workspace Clippy and WebAssembly Clippy with warnings denied: passed.
- Dioxus release UI and native server builds: passed, including the final retry change.
- Live check: **Attack on Titan Season 3 Part 2**, native Nyaa, **291 releases / 27 matched**,

  action was invoked. Existing custom-format minimum 500 rejected the matching releases with
  score 0. The existing library stayed at 80 series and 14 movies.
- Chromium: **1 passed in 173.74 seconds**. It covers direct Nyaa season searches, a second
  click of the same-target search button that reaches the source again, explicit retry,
  unavailable sources, valid empty feeds and partial source failure. Existing library/import
  flows, 16 pages at 10 browser zoom levels (50–400%), catalogue dialogs at each zoom and four
  pages with 20 px default text also passed.
- Final local server and web UI return HTTP 200; native Nyaa is configured with RSS off,
  automatic search off and interactive search on. The existing library and profiles are kept.
