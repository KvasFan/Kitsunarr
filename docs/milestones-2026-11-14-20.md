File operations require a registered, available root folder. Paths outside the film folder,
parent traversal, symbolic links and destinations already in use are refused. Scans never
move files and do not replace an existing feature with another candidate. Catalogue and
service fixtures are simulated; filesystem tests use temporary directories.

Whole-folder recycling requires the recycle bin to be on the same filesystem. A failed
folder move leaves the original folder and title in place. Feature-file recycling also
supports a different filesystem using a no-overwrite copy before unlinking the source.
