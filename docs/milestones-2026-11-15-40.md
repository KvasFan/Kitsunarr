## Watched status

Movie detail pages provide **Mark watched / Mark unwatched** and show the watched timestamp.
The movie library filters watched/unwatched titles, sorts by watched date, and supports
selection and bulk watched or monitoring actions in poster and table views.

Manual watched changes preserve monitoring. Metadata refreshes, catalogue changes and file
upgrades preserve watched state; repeated migration does not overwrite a local watched choice.
With Jellyfin watched sync enabled, the next valid snapshot follows Jellyfin's current played
state. A feature absent from a snapshot is left unchanged. Conflicting remote played flags
reject the snapshot; paths shared by different local files are skipped. Tag scope also
applies to films. Film and episode changes commit in one transaction.

Automatic unmonitoring and remonitoring use the existing Jellyfin connection options. An
explicit single or bulk monitoring edit clears automatic ownership, so a later unwatched
sync cannot reverse that choice. Another connection cannot remonitor a film owned by a
previous connection. Film watched flags do not enqueue series import-list progress writes.
